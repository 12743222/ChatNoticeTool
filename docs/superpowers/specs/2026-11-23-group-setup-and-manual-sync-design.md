# 群聊标定向导与无 AI 手动同步设计

- 日期：2026-11-23
- 状态：已确认，实施中
- 范围：桌面端群聊发现/标定向导、无 DeepSeek Key 的本地手动读取与待办生成

## 1. 目标

- 让不会命令行或 AI 的用户在桌面软件内完成 QQ/微信来源发现、群聊列表读取和勾选标定。
- 提供完全不调用模型的“读取群消息”功能：本地读取、初步过滤、人工确认后生成待办。
- 明确展示填写与不填写 DeepSeek Key 的能力差异。
- 保留现有 AI 自动读取流程，两者互不影响。

## 2. 非目标

- 不读取联系人、私聊、朋友圈或其他非群聊会话。
- 不自动发送消息、不修改客户端数据库。
- 不自动勾选全部群；不删除历史待办或消息。
- 不在无 AI 模式下做语义理解或可靠日期解析。

## 3. 群聊标定向导

入口：设置 → “群聊标定”。

### 3.1 步骤一：检测

- QQ：调用 `agent_setup.py source candidates --platform qq` 获取候选路径。
- 微信：同样尝试候选；额外扫描固定磁盘的 `xwechat_files/*/db_storage` 和当前用户文档目录；找不到时提供文件夹选择。
- 检测当前 QQ/微信客户端进程数（QQ.exe、WeChat.exe、Weixin.exe），不读取内存。
- 展示已配置来源和已标定群数量；已有来源不重复添加。

### 3.2 步骤二：授权

- 用户必须勾选明确的隐私说明：一次性读取本人客户端内存中的数据库凭据，仅用于列出群名，不读取正文、不保存密码。
- 后端为每个平台：
  1. 若来源未配置，用最新 revision 调用 `source configure`；
  2. 调用 `source check`；凭据未就绪时调用 `source connect --pid <所有客户端PID> --authorize-memory-read`；
  3. 返回该平台成功/失败状态。
- 客户端未登录或路径错误时给出可操作提示，不扩大扫描。

### 3.3 步骤三：选择群

- 分别展示各来源的群名/群号，支持搜索、全选当前筛选。
- 已标定启用的群默认勾选；已标定但停用的群默认不勾选。
- 保存规则：
  - 勾选的新群：新增并启用；
  - 勾选的已有群：启用；
  - 取消勾选的已有群：停用（不删除历史）；
  - 未勾选且未标定的群：不写入。
- 写入使用最新 revision 和 `confirmed: true`；超过 100 个群时分批提交。

### 3.4 步骤四：完成

展示 DeepSeek Key 能力对比：

| 不填 Key | 填写 Key |
| --- | --- |
| 手动点击读取群消息 | 自动定时读取 |
| 本地规则过滤，免费 | AI 语义理解、日期/链接/地点提取 |
| 人工勾选后生成待办 | 自动生成待办 |
| 图片不识别 | 候选正文发送给 DeepSeek |

提供“暂不填写，使用手动读取”和“保存并启用 AI”两个出口。

## 4. 无 AI 手动同步

入口：待办栏头部“读取群消息”按钮；设置页也提供入口。

### 4.1 读取与过滤

- 新增本地接口 `POST /api/sync/read`：调用 `agent_cli.py read`，不要求 API Key，不调用模型。
- 返回本批次新消息/变化消息/未完成消息的文本、群名、时间、发送者、附件名和 `likely_notice` 标记。
- 默认只显示“可能相关”消息；可切换“显示全部”。
- 本地规则：
  - 群公告卡片、@全体成员直接标记；
  - 命中报名/缴费/截止/提交/会议/比赛/讲座/领取/填写/登记/链接/问卷等关键词，或含明确日期/时间/URL；
  - 排除空消息、撤回/系统消息、纯图片视频、纯表情、明显短闲聊；
  - 规则仅做初筛，不保证准确，全部消息始终可查看。

### 4.2 人工确认

- 勾选消息后可执行：
  - 生成待办：标题取首行，说明保留原文和来源信息；
  - 按规则生成：清洗 @、表情和多余空白，生成更整洁的标题/说明；
  - 忽略选中：标记 skipped，不再出现在后续读取中；
  - 忽略全部未选：批量清理当前列表。
- 未处理的消息保持 pending，下次读取仍会出现。
- 生成/忽略通过 `agent_cli.py write` 写入，自动关联消息和待办。
- 不调用 DeepSeek，不产生模型费用。

## 5. 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/setup/scan` | 检测来源候选、进程、已配置来源/群数 |
| POST | `/api/setup/authorize` | 配置来源并按用户授权取钥 |
| GET | `/api/setup/groups` | 读取指定来源的群名/群号 |
| POST | `/api/setup/groups` | 保存勾选结果 |
| POST | `/api/setup/folder` | 选择微信数据文件夹 |
| POST | `/api/sync/read` | 本地读取消息并返回规则标记 |
| POST | `/api/sync/commit` | 生成待办或忽略消息 |

所有接口仅限本机访问；不向局域网/公网开放。

## 6. 安全

- 取钥需用户显式勾选确认；内存授权仅本次调用，不持久化。
- 不读取消息正文用于群列表；群列表只返回群名/群号。
- 无 AI 模式消息正文不离开本机。
- 写配置使用最新 revision；出错时不重试写入不同内容。
- 日志不包含聊天正文、密钥、令牌。

## 7. 错误处理

| 情况 | 行为 |
| --- | --- |
| 客户端未登录/未运行 | 提示打开并登录后重新检测 |
| 微信路径不存在 | 提示选择 `xwechat_files` 下的账号目录 |
| 取钥失败/权限不足 | 提示关闭占用程序、同权限运行或重新授权 |
| 群列表为空 | 提示确认账号/路径，不写入配置 |
| 配置冲突 | 重新读取 revision，展示变更后重试 |
| 无标定群 | 手动读取提示先完成群聊标定 |
| 读取或写入失败 | 保留 pending，显示错误，不产生半成品待办 |

## 8. 测试

- 向导：现有来源、候选路径、微信自定义路径、客户端进程、授权失败、群列表、勾选/取消/停用、超过 100 群分批。
- 无 AI 同步：公告/@全体命中，关键词/日期/URL 命中，闲聊/空消息/纯图片过滤，全部视图，生成/规则生成/忽略，未选消息保留 pending，模型调用数为 0。
- UI：四步向导、搜索/全选、手动同步模态、错误提示、窄窗口滚动。
- 验收：不填 Key 也能读取并创建待办；填写 Key 的自动读取行为不变；联系人和私聊不可见。
