# ChatNotice 使用与配置说明

本文面向第一次使用 ChatNotice 的同学，说明桌面端、手机端和可选自动读取功能的配置方法。

## 1. 系统要求

- Windows 10 或 Windows 11，64 位。
- 需要 Microsoft Edge WebView2 运行时；现代 Windows 一般已自带。如果窗口打不开，请安装微软官方的 WebView2 Evergreen Runtime。
- 不要放在 `C:\Program Files` 等需要管理员权限的目录。建议解压到 `D:\ChatNotice` 或桌面文件夹，路径不要包含特殊符号。
- 首次启动时 Windows 防火墙可能弹窗，请勾选“专用网络”和“公用网络”并允许，否则手机连不上。

## 2. 启动与退出

1. 解压压缩包，进入 `ChatNotice` 文件夹。
2. 双击 `Start ChatNotice.bat`。
3. 成功后会出现 ChatNotice 窗口，并在系统托盘生成图标。
4. 点击窗口右上角关闭，只是隐藏到托盘，程序仍在运行（自动读取和手机同步需要它保持运行）。
5. 彻底退出：右键托盘图标 → 退出。
6. 如果双击没有反应，运行 `Start ChatNotice (debug console).bat`，窗口里会显示错误信息。

## 3. 基本使用

- **任务气泡**：把文字拖进气泡，或把图片、文件拖进去；也可以手动输入。点击“加入待办”保存。
- 拖入的文字只显示一行摘要，鼠标移上去可点 × 清空；图片显示缩略图，点击可看大图。
- **待办列表**：左侧勾选框完成任务（有粒子消融动画）；点击标题打开详情，可改标题、截止时间、说明、附件预览。
- **已完成待办**：待办栏底部按钮，可查看已完成任务并撤销。
- **上传素材**：待办栏底部按钮，可快速把文件加入第一个气泡。
- **读取群消息（不用 AI）**：设置 → 群聊与同步 → 读取群消息，或点待办栏顶部的下载图标。选择“仅 QQ / 仅微信 / 全部”和时间范围后读取；默认只显示可能相关的通知，可切换显示全部。勾选消息后可以“生成待办”“按规则生成”或“忽略”，全程本地完成，不调用模型、不产生费用。
- 所有数据保存在软件目录下的 `state` 文件夹中。

## 4. 手机连接

### 4.1 安装手机 App

压缩包内附 `ChatNotice-mobile.apk`。传到安卓手机后安装；系统提示“未知来源”时允许本次安装。

### 4.2 同一 Wi-Fi（局域网）

1. 电脑端点击顶部手机图标，打开“手机配对”。
2. 选择“局域网”，保持手机和电脑连接同一个 Wi-Fi。
3. 手机打开 ChatNotice，配对页选择“局域网”，点“扫码连接”，扫描电脑上的二维码。
4. 连接成功后即可同步待办。

如果连接失败：

- 确认电脑防火墙允许 ChatNotice 访问网络；
- 确认路由器没有开启“AP 隔离/访客网络隔离”；
- 也可以在手机端手动填写电脑显示的地址和令牌。

### 4.3 任意网络（公网）

1. 电脑端配对弹窗切换到“公网”。
2. 打开“公网访问”开关，等待状态变为“已就绪”（首次需要下载隧道组件，可能需要几十秒）。
3. 手机配对页选择“公网”，点“扫码连接”扫描二维码。
4. 使用完成后可以关闭公网开关，公网地址立即失效。

注意：

- 公网地址是临时的，电脑重启或重新开启后会变化，需要重新扫码。
- 公网访问仍然需要令牌；不要把二维码或令牌发给别人。
- 待办内容会经过 Cloudflare 传输，请勿在其中保存高度敏感信息。
- 电脑休眠、关机或退出 ChatNotice 后，公网连接会中断。

## 5. 自动读取群消息（可选，进阶）

> 普通用户只用气泡和待办时，不需要配置这一节。
> 自动读取需要你自己的 DeepSeek API Key，以及本机的 QQ/微信聊天数据访问配置；软件包默认不包含任何聊天配置。

**不填 Key 也能用**：设置 → 群聊与同步 → “读取群消息”，手动读取后按本地规则初筛、人工勾选生成待办；不联网、不产生模型费用。
**填 Key 后**：才能使用按时间段的自动读取和 AI 语义生成待办。

### 5.1 配置 DeepSeek

1. 在 https://platform.deepseek.com/ 注册并创建 API Key。
2. 电脑端设置（右上角齿轮）→ 拉到“AI 进阶设置”。
3. 填入 API Key 并保存。密钥使用 Windows DPAPI 加密，仅当前 Windows 用户可解密。
4. 模型默认 `deepseek-flash`；每日调用上限默认 20 次，可自行修改。

### 5.2 启用自动读取

1. 在设置里打开“隐私确认”（表示你同意把候选消息正文发送给 DeepSeek）。
2. 打开“自动读取”开关。
3. 设置允许读取的时间段（默认 08:00–22:00）、检查新消息间隔、完整读取最短间隔。
4. 保存后，桌面端在时间段内自动检查；有新消息才调用模型并生成待办。
5. 每次打开软件会立即读取一次：不受“完整读取最短间隔”限制，但仍受每日调用上限约束；如果只想在时间段内读取，可在设置里关闭自动读取，或告诉我改成受时间窗限制。
6. 也可以点“立即读取一次”手动触发。

达到每日调用上限后，当天只读取、不调用模型，第二天自动重置。

### 5.3 配置聊天来源

推荐使用软件内的向导：设置 → 群聊与同步 → “识别群聊”。

1. 打开并登录 QQ/微信客户端；
2. 向导检测数据目录和客户端进程；微信自定义目录找不到时点“选择文件夹”；
3. 勾选授权说明，点击“允许并识别”（一次性读取本人客户端内存中的数据库凭据，仅用于列出群名）；
4. 在列表里搜索、勾选要标定的群，保存；
5. 完成后可选择“暂不填写 Key，使用手动读取”或去填写 Key。

如果向导失败，或需要更细的来源/授权控制，可按以下文档手动配置：

- `docs/agent/configuration.md`（来源、选群、授权）
- `docs/agent/workflow.md`（读取与写入待办流程）
- 常用命令：`runtime\python.exe -B -X utf8 agent_setup.py inspect`

如果你只是想把 ChatNotice 当待办工具使用，跳过这一节即可。

### 5.4 交给本地 AI 助手配置（推荐给不想敲命令的人）

压缩包内附 `AI-配置指南.md`。把解压目录和这份文件交给能访问本机文件、能执行命令的本地 AI 助手（例如 Qoder、Claude Code 等），让它按指南完成：

1. 探测/确认 QQ 或微信数据库路径；
2. 添加来源；
3. 在你本人授权下获取本机数据库凭据；
4. 列出候选群，由你确认要标定的群；
5. 写入群配置；
6. 告诉你在桌面设置里填写 DeepSeek Key 并启用自动读取。

注意：联系人、私聊仍然不支持；AI 不能代替你做取钥授权，也不会替你决定标定哪些群。

## 6. 数据、隐私与备份

- 所有个人数据在软件目录的 `state` 文件夹：
  - `todos.sqlite3`：待办数据；
  - `processing.sqlite3`：群消息处理记录（仅配置自动读取后出现）；
  - `api-token.txt`：手机访问令牌；
  - `model-secrets.dpapi`：DeepSeek 密钥（DPAPI 加密）；
  - `automation.json`、`remote-access.json`：自动读取和公网开关设置。
- 不要把自己的 `state` 文件夹发给别人，里面有你的待办、令牌和密钥。
- 备份：退出 ChatNotice 后复制整个 `state` 文件夹即可。
- 迁移到新电脑：复制整个软件文件夹；DPAPI 密钥不能跨 Windows 用户解密，需要在新电脑重新填写 DeepSeek Key。

## 7. 开机自启

设置 → 启动 → 打开“开机自启”并保存。关闭开关或删除软件前，建议先关闭此开关，避免留下无效启动项。

## 8. 常见问题

**窗口打不开 / 白屏**
安装 WebView2 Runtime；或运行 debug 启动脚本查看错误。

**手机扫码后连不上**
确认电脑端 ChatNotice 仍在运行；公网模式确认状态为“已就绪”；局域网确认在同一 Wi-Fi 且未被 AP 隔离；公网地址变化后重新扫码。

**提示 401 / 令牌不正确**
二维码或手动输入的令牌过期/错误，重新扫码或从电脑端复制当前令牌。

**公网地址打不开**
电脑重启后旧地址已失效；重新开启公网并重新扫码。公司/校园网络可能限制外网访问。

**相机打不开**
在手机系统设置中允许 ChatNotice 使用相机；或点“从相册选择”识别二维码截图。

**自动读取没有生成待办**
确认 API Key、隐私确认、自动读取开关均已开启；确认已配置聊天来源；查看设置里的“上次结果”和“今日调用次数”。

## 9. 卸载

1. 托盘右键退出 ChatNotice。
2. 设置里关闭开机自启。
3. 删除整个软件文件夹（如需保留数据，先备份 `state`）。
